Project & Architecture Overview

Project Name: National Car Import Supply Chain Platform (NCI-SCP)
Architecture: Django Full-Stack MVC & REST API Pipeline
Database Layer: SQLite3 Relational DB (Django ORM)
Security Engine: SHA-256 Cryptographic Digest Verification
Active Environment: Production Ready (Development Server Active)

Active REST API Endpoints

GET /api/dashboard/ Dashboard KPIs & Recent Consignments
GET/POST /api/shipments/ List, Filter & Create Consignments
POST /api/shipments/<id>/advance/ Advance Supply Chain Workflow
GET /api/track/?q=... Real-Time Tracking by VIN or ID
GET/POST /api/documents/ Document Registry & SHA-256 Hash
GET /api/reports/export/ Export Summary in JSON or CSV

Ethiopian Automotive Import Framework

📜
Customs Proclamation No. 859/2014

Governs valuation, tariff classification, physical inspections, and penalty schedules for undeclared items.

⚡
Electric Vehicle (EV) Incentive Policy

Complete customs duty exemption and reduced VAT rates for fully electric passenger vehicles to foster green logistics.

🚆
Multimodal Transport System (ESLSE)

Mandatory through Bill of Lading from Port of Origin directly to Modjo/Kality Dry Ports via Ethio-Djibouti Railway.
